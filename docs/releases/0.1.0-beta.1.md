package version。

## 本版內容

- 單一 Stage 的個人／團隊知識工作區。
- 由 Krepis ABI 1.8 管理的 Flow Block 編輯、visual geometry、保存、undo/redo 與 Ink capture。
- FileExplorer、標題／資料夾快速搜尋、session startup preference。
- Journal、資產庫與 Notist AI 的真實 empty/unavailable 狀態。

## 預定安裝與驗證

1. 從核准的 GitHub Private Prerelease 下載 ZIP 與同名 `.sha256`。
2. 在 PowerShell 執行：

   ```powershell
   Get-FileHash .\Notist-0.1.0-beta.1-windows-x64.zip -Algorithm SHA256
   ```

3. 確認輸出與 `.sha256` 完全相同後再解壓縮。
4. 從解壓縮目錄執行 `notist.exe`，不要單獨搬移 EXE。

## 未簽章警告

這個 Private Beta 尚未進行 Windows 程式碼簽章，因此 Windows Defender SmartScreen 可能顯示
來源不明警告。看到的 publisher 不應被解讀為已驗證的發行者。只使用 Private Prerelease
附帶的 SHA-256 驗證成品；無法驗證時不要執行。

## 已知限制

- 快速搜尋不包含全文或 Block identity。
- Journal、資產庫與 Notist AI 沒有 provider 資料或寫入能力。
- Block 層級刪除、跨 Block 文字拖選、Ink eraser/lasso 與多工具快捷鍵尚未提供。
- 未包含 tabs、split、Inspector、協作與雲端同步。
- Beta 期間的本機資料格式可能變動；升級或回退前應備份 `%LOCALAPPDATA%\Notist\Flows`。

## 回退

若發現資料完整性、ABI 或啟動問題，請停止使用候選版、保留資料目錄備份，並回報安全或產品問題。
在有可驗證的前版 Beta 前，不建議將較新資料檔交由 alpha 版開啟。
